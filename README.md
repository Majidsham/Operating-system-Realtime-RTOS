## Student Assignment: Process Scheduling Algorithms

As part of this course, each student is required to select and present **one process scheduling algorithm**.

Each student will be responsible for introducing a different scheduling algorithm, explaining how it works, implementing it in Python, and demonstrating its behavior through practical examples.

### Assignment Requirements

Each student should:

1. **Select an Algorithm:** Choose one process scheduling algorithm in coordination with the instructor to avoid duplicate selections.
2. **Explain the Algorithm:** Describe its principles, operation, advantages, and limitations.
3. **Implement in Python:** Develop a working Python implementation of the selected algorithm.
4. **Run a Simulation:** Test the implementation using sample processes with different arrival times and CPU burst times.
5. **Analyze the Results:** Calculate and explain the waiting time, turnaround time, and average values. Where applicable, analyze response time and scheduling behavior.
6. **Present the Work:** Prepare a short presentation explaining the algorithm, implementation, and experimental results.
7. **Upload to GitHub:** Publish the source code, README documentation, sample inputs, and results in a GitHub repository.

### Suggested Algorithms

Students may choose from the following algorithms:

- First Come, First Served (FCFS)
- Shortest Job First (SJF)
- Shortest Remaining Time First (SRTF)
- Round Robin (RR)
- Priority Scheduling
- Multilevel Queue Scheduling
- Multilevel Feedback Queue Scheduling
- Rate Monotonic (RM)
- Earliest Deadline First (EDF)

Additional algorithms may be selected with the instructor's approval.

### Expected Learning Outcomes

By completing this assignment, students will gain practical experience in process scheduling, algorithm implementation, performance analysis, and technical documentation. They will also learn to compare scheduling strategies and understand how scheduling decisions affect system performance and real-time constraints.

## About the Course

In this course, we explore the fundamental concepts and practical challenges of embedded systems and real-time computing, including:

- Real-Time Operating Systems (RTOS)
- Processes, Threads, and Tasks
- Process and Task Scheduling Algorithms
- Real-Time Scheduling: Rate Monotonic (RM) and Earliest Deadline First (EDF)
- Critical Sections and Mutual Exclusion
- Semaphores, Mutexes, and Monitors
- Deadlocks and Resource Management
- Inter-Process Communication (IPC)
- Priority Inversion and Priority Inheritance
- Embedded System Design and Practical Implementation

## Practical Assignments and Projects

Throughout the semester, students will work on programming assignments, algorithm implementations, experiments, and practical projects related to embedded and real-time systems.

Topics may include:

- Implementing CPU scheduling algorithms using Python
- Simulating task scheduling and analyzing response times
- Implementing synchronization mechanisms
- Exploring race conditions and critical-section solutions
- Simulating deadlock scenarios and prevention techniques
- Analyzing real-time task deadlines and system performance
